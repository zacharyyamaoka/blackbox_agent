# feedback/

One note per piece of feedback (`<date>-<slug>.md`: Observed / Desired / Why), filed when an agent acts on it.

Front matter the dashboard reads (each optional): `spec: [O4.3]` (the spec it became), `tags: [bug-report]` (a bug
report, which also names its `source:`), `status: obsolete` with `obsolete_why:` (kept, drawn struck through), and
`entered_by: user` or `ai` (who typed it in). `blackbox check` holds them.
